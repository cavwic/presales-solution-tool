售前解决方案工具 V1.6.0

启动
双击“售前解决方案工具.exe”。程序自带界面运行环境，无需安装 Node.js、Astro 或手动启动网页服务。
移动或备份软件时，请保留 EXE 所在文件夹的完整内容。

更新
在本机源码项目中运行 npm run update:desktop。更新入口先验证候选版本，再关闭当前工具、替换固定运行目录并复验；失败时恢复原版本。
原运行文件只在更新过程中临时保留用于失败恢复。更新成功后，仅保留当前最稳定运行版及对应 ZIP，不长期保留历史版本或回退包。
更新不以项目资料目录或 %APPDATA%\CavwicBidWorkbench 为输出目录。便携版需完整解压，退出旧程序后再切换使用。

使用
1. 选择“项目路径”，新建或打开本地项目目录。
2. 导入项目资料和招标文件，按售前准备、招标要求、技术标组包、中标交底处理。
3. 在顶栏第二行选择“本地模型 / 模型套餐 / API / 混合”，需要时展开模型设置；新建项目和项目设置位于页面大标题下方。
4. 完成资料预处理和招标分析，选择参考资料、输出格式和模板，生成投标文件。
5. 在“输出文件”选择文件，输出目录或导出 ZIP。
6. “文件清理”位于页面大标题下方，先扫描并勾选，再确认清理。现存项目生成文件移入回收站；原始资料、模板和模型设置保留。下载到其它位置的副本需自行处理。清理生成文件后，当前撤销记录会重置。

模型
本地模型：点击顶部“本地模型”展开设置，选择 Ollama、LM Studio 或其他兼容服务。
  Ollama 默认服务地址 http://127.0.0.1:11434，使用原生聊天与模型目录接口。
  LM Studio 默认服务地址 http://127.0.0.1:1234/v1，需先在 LM Studio 中开启本地服务器。
  其他兼容服务支持 OpenAI Chat Completions 协议，例如 llama.cpp、LocalAI、vLLM；按对应工具填写服务地址。
  地址可填写服务根地址、API 基础地址或完整聊天接口。读取模型列表后选择，也可手动输入模型 ID；列表读取不会自动选择模型或标记生成测试通过。
  未读取到模型时，先在对应工具中准备模型并启动服务。工具不会自动下载模型、安装运行环境或启动其他模型工具。
  本地服务启用认证时可填写独立访问令牌，仅保留在本次应用会话；退出后需重新填写。云 API 密钥不会发送给本地模型。
模型套餐：在设置中选择接入方式。
  ChatGPT 套餐（Codex）：沿用本机已安装、已登录的 Codex CLI。可以读取模型列表或填写完整模型 ID；留空使用当前默认模型。本工具不会安装 CLI、导入账号 Cookie 或修改 Codex 全局配置。
  MiniMax 套餐：填写 M Plan / Token Plan 订阅 Key、官方地址和模型 ID。按量 Key 使用独立计费规则，不能当作订阅 Key。
  其他授权套餐 / 接口：可选择 Claude、Gemini、Grok、DeepSeek、Qwen、Kimi、GLM 等服务商预设，也可自定义地址。支持 OpenAI Chat Completions、Anthropic Messages 和 Gemini GenerateContent。
  仅使用厂商允许本工具调用的接口与密钥。服务商预设不是网页会员接入证明，网页会员不会自动转换为 API 额度；有工具范围限制的 Coding Plan 不作为本工具自动调用额度。需要独立 API Key 的服务按厂商接口规则计费。
  可导入 JSON 配置，支持 endpoint/base_url/baseUrl、model、protocol、vendor 及可选 apiKey/api_key。点“配置示例”可保存格式示例；不导入 Cookie、OAuth token 或账号密码。载入后检查地址和计费方式，再保存配置。
  套餐密钥与本地访问令牌、云 API 密钥分开，仅保留在当前会话。切换接入方式、服务商或修改套餐地址会清空当前编辑的套餐密钥，需重新填写。
  非 Codex 服务暂不读取账号模型目录，请填写厂商提供的准确模型 ID。生成结果记录接口实际返回的模型 ID。
API：填写兼容接口、模型名称及自己的 API Key，按该接口的规则计费。
混合：勾选启用的通道，分别为资料分析、文件生成和图像识别指定通道。请求失败时会报错，不会自动切换到其它通道。
“测试生成”完成一次短生成才会显示验证成功；读取模型列表不代表生成已通过。
程序不会把未确认事项改为已满足，也不会替你向采购平台提交或签章。
扫描件需使用支持图像识别的模型进行 OCR；纯文本模型不能识别图片。

Skills
模型行后方“导入 Skills”可上传单个 SKILL.md 或单 Skill ZIP，也可从公开 GitHub 的 Skill 目录、SKILL.md 或单 Skill ZIP 安装。
新导入的 Skill 默认不启用，查看指引、参考文本与来源后，可在列表中启用。已启用的 Skills 由本地模型、模型套餐、API 和混合模式共同使用，切换模型无需重复导入。
导入的是工作指引和支持的参考文本；附带脚本、程序、依赖及二进制附件不会自动执行或加载。模型是否遵循指引取决于其能力，导入 Skill 不会赋予模型新的工具权限。
SKILL.md 须使用 UTF-8，包含 name、description 和正文；单文件最大128 KB，ZIP最大16 MB、最多128项，解压总量最大12 MB。同名 Skill 不会覆盖，暂不支持包含多个 Skill 的仓库整包。上下文有长度限制，较长内容会截短。
联网安装仅访问公开 GitHub，不使用你的 GitHub 令牌、不安装软件依赖。公司内网、私有仓库和其他来源可先自行下载，再上传单 Skill ZIP。
Skills 单独保存在 %APPDATA%\CavwicBidWorkbench\tool-skills，普通缓存清理不删除这些配置。

本地数据
项目资料保存在你选择的目录。应用配置和界面缓存位于：
%APPDATA%\CavwicBidWorkbench
云 API Key、本地访问令牌与套餐接口密钥分别保留在本次应用会话，不写入项目清单或磁盘配置，仅发送到对应通道。
对已有本地文件进行覆盖写入时，上一份内容备份至应用数据目录 file-backups。

线上项目迁移
选择线上版此前使用的项目目录，可继续处理该目录中的项目。
仅存在网页浏览器缓存中的内容不会自动进入桌面版。
“导出为 ZIP”是所选业务文件的交付包；“导入 ZIP”兼容原工作台的项目归档格式，交付包不等于完整项目备份。

界面
默认中文、主题跟随系统。撤销和恢复位于左上工具名称右侧；右上角依次为语言、主题、最小化、最大化/还原、关闭。
窗口边缘可拖动缩放，顶栏空白处可拖动窗口。
正文宽度随窗口扩展，大屏文字与控件适度放大；窄窗口自动重排，表格可在区域内横向滚动。
