# V1.6.0 发行说明

本版整理项目目录、文档和桌面构建流程，模型与业务工作流沿用 V1.5.0。

## 变化

- README 保留快速开始和功能入口；模型、Skills、开发、验证及发行说明分别放入 `docs/`。
- 当前桌面验收迁至 `tests/desktop/`，报告和隔离测试数据统一输出到 `.cache/validation/`；本机配置及历史验收材料不随源码发布。
- 安装检查成功并关闭测试实例后清除隔离 profile，保留报告与验收截图；失败时保留诊断数据。
- 新增原位更新入口 `npm run update:desktop`：候选安装检查通过后替换固定运行路径，再检查正式安装及 ZIP。桌面和开始菜单继续使用固定根启动器。
- 只保留当前稳定运行目录及对应便携包。更新过程中的临时恢复副本在成功后删除，历史发行副本和已审计的冗余测试缓存按此规则整理。
- 构建路径使用环境变量、本机配置或项目依赖解析，共享脚本不再绑定个人机器目录。
