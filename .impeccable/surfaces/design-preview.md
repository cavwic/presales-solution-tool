Mode: Operate. Target: `/design-preview/` and its four style routes.

The user requested four working visual studies of the existing presales tool: Linear, Fluent 2, Notion, and shadcn/ui. These are fictional comparison previews; the Linear study was subsequently selected for the production workspace. Keep real project data separate from every preview.

All studies use the same fictional campus project, editable project context, five lifecycle stages, document list, action checklist, model modes, Skills, project settings, and cleanup controls. Generation and filesystem actions are explicitly non-executing previews. Labels, states, dialogs, and tooltips are localized in Chinese and English.

Respect the user's local GUI requirements: frameless window, title/taskbar identity, language-theme-minimize-maximize-close order, system-following initial theme, adjustable window size, concise copy, comfortable type, and copyable text. The desktop preview uses the existing runtime and an isolated profile, without copying the app runtime or modifying production data.

The studies compare four compositions: A compact three-column project workspace; B Windows navigation plus grouped property controls; C document-first inline editing; D tabbed data and task workspace. Preserve the blue action accent. Production behavior is documented in workspace-linear.md; these study controls do not perform production operations.
